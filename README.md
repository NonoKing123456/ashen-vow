# 灰烬誓约 · 钟鸣之章 / ASHEN VOW

[当前公开版本 v14](https://nonoking123456.github.io/ashen-vow/?v=14) · [独立 GitHub 仓库](https://github.com/NonoKing123456/ashen-vow)

一个可直接在浏览器游玩的原创第三人称动作短关卡。穿过雨夜回廊，挑战两名守卫，在余火小堂选择赐福，面对二阶段无冠守望者，亲手敲响最后的古钟。

## v15 开发候选 · 角色动作与完整性（尚未发布）

本轮冻结场景、美术与新内容，集中修复基础行为与真实生产资产的旅途连通性。

- 固定 60Hz 战斗步进，渲染独立；20/30/60/120Hz 下的移动、攻击、旅途计时和命中停顿一致。暂停、菜单及后台时间不追补，长卡顿限制追赶预算。
- 攻击辅助只面向有限前向区域；危险提示选择实际出招者；暂停忽略重复按键。重叠的可交互物件按最近距离选择。
- 重新校准手掌横轴与剑柄，采用真实重定向剑术动作、分离的收势及同一持剑基线。翻滚采用真实全身源动作与独立武装适配，取消此前未经认可的低步闪身方案。侧后方向目前为转身后向前滚，尚无独立侧滚/后滚资源。
- 攻击、收招、根位移、无敌阶段与源动作共同标定；剑盾、身体和地面按下述范围逐项检查。源动画数值与自动测试不能作为观感通过的证据。
- 导航在动画完成后继续约束真实身体与装备的最终轮廓，覆盖墙角闪避和倒地。门扇碰撞跟随实际门板运动，重试与载入同时恢复视觉与碰撞。
- 新增真实 GLB、完整角色约束和实际关卡障碍的全旅途整合检查；原可控剑刃夹具继续只验证规则。自动驾驶不证明人类可读性，也不等于人工完整通关。

## v14 · 角色、装备与碰撞的一致性（历史阶段）

这一阶段增加了装备结构与有限接触检查，后续审查确认仍存在墙角翻滚穿模和动作管线问题，不能据此认定完成整体验收。

- **实体装备与掌心握持**：盾牌有封闭背板、木芯、铁箍和握带；指节闭合，剑盾锚在掌心。剑刃从护手之外开始，避免钢片穿入握柄。普通持剑、戒备、格挡与攻击收势使用同一套臂部约束。
- **步态**：按真实足底与源动画步幅校准走跑相位；普通移动 1.85 m/s，冲刺 4.4 m/s，举盾 1.05 m/s。倒退与侧移保留朝向关系，脚步声跟随落脚；顶住墙时停止步态和冲刺消耗。
- **完整接触**：修正交错骨权读取，统一处理脚底、武器、盾牌、披风与地面的接触；翻滚和倒地时考虑装备支撑。以实际蒙皮三角采样检查刀刃与盾盘切入身体，贴墙时收持装备，剑撞实物会中断攻击。
- **场景实体**：角色间距分离也受静态碰撞约束；调整人体包络，补齐可接近的墓碑、底座、雕像和柱脚碰撞。倒塌石材的旋转范围与高度来自其真实形状。
- **恢复与验收**：恢复时保持装备，腰间余烬之瓶与动作共鸣。开发检查页 `review.html` 使用生产角色，支持前后侧、慢放、逐帧及墙角检查；不进入游戏菜单。每轮发布遵循 `AGENTS.md` 的整体验收规则。

## 已有旅途与玩法

- **动作**：方向性低身闪避，使用同一套握持与最终接触流程；走跑由真实位移驱动，源步态提供保守的支撑窗口。
- **战斗（历史）**：闪避后的短窗口可接突刺（v15 候选已改为实装斩击）；精准格挡强化下一剑。守卫轮流进攻、支援侧移，超出范围后归位。Boss 按距离、喝药和持续格挡选择可读的招式，半血阶段转换等待当前攻击完成。暂停保留反击窗口。
- **探索与成长**：三处有实体物件的可读残响，首次发现补充一瓶药；小堂提供生命、耐力、剑伤三选一赐福，可重新选择且不叠加。地图手记记录玩家位置、发现与战斗统计。
- **终章**：击败 Boss 后仍可探索；走到实体钟绳前按 F 敲钟结束。钟摆、声波、雨势和灯光共同变化。
- **操作**：键鼠默认移动鼠标即转镜头，无需按住拖动；支持 Pointer Lock，Esc 释放并暂停。不支持锁定的浏览器可直接悬停控制镜头。标准手柄支持战斗、双摇杆、冲刺、菜单与可用时的震动。
- **呈现与设置**：保留本地 PBR 材质与雨夜风格，增加云层、独立音乐/音效/主音量、灵敏度、减少动态和引导开关。弹窗保留暂停状态；可返回标题、继续与重试。进度与设置只保存在当前浏览器。

## 本地开发与检查

需要 Node 20+，无运行时安装依赖：

```sh
npm start
npm test
```

访问 http://127.0.0.1:8080 。GitHub Pages 从 `main` 根目录发布，所有运行资源使用相对路径，无 CDN 依赖。

自动检查分别覆盖生产 GLB、实体装备、步态、接地、身体与装备接触、移动与拥挤碰撞、战术、输入、UI、声音、存档、实际关卡和演出，以及仅通过公开控制完成两守卫、检查点、开门、两阶段 Boss 和敲钟的流程。接触检查使用实际蒙皮后的三角采样；控制器流程使用可控剑刃夹具，两者分开验证。演出整合包含计时冻结、自然结束、跳过和鼠标解锁。手柄以可注入 Gamepad API 验证，未使用实体手柄验收。

## 资源与结构

Knight 为 Patch/anymove 的 CC0 真实蒙皮资产：59,281 三角形、22 骨骼、UV 与 PBR 贴图。它是有明确许可的基础资产；不是自行雕刻的人体模型。原始走跑使用来源动画；剑术与翻滚来自明确许可的 Quaternius Standard 动作包，经骨架与掌面校准后驱动原模型。武装翻滚另行适配剑盾，接触约束在混合后执行。完整出处见 `assets/ASSET_CREDITS.md`。

`game.js` 负责整合，`feel.js` 管理战斗时序，`navigation.js` 负责位移碰撞；`characters.js` 创建角色与实物，`locomotion.js` 校准步态，`motion.js` 混合动作，`rig-constraints.js` 统一握持与接触。`tactics.js`/`journey.js` 管理战术与旅途；`level.js`/`surfaces.js`/`weather.js` 负责场景；`director.js`/`impact.js` 负责演出和火花；`render.js`/`audio.js`/`controls.js`/`ui.js` 负责呈现与交互。

这是持续改进的浏览器动作短关卡。场景建筑仍为程序化制作；自动检查通过不等于已经达到商业游戏的美术、动作捕捉或性能标准。
