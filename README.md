# 灰烬誓约 · 钟鸣之章 / ASHEN VOW

[直接游玩 v13](https://nonoking123456.github.io/ashen-vow/?v=13) · [独立 GitHub 仓库](https://github.com/NonoKing123456/ashen-vow)

一个可直接在浏览器游玩的原创第三人称动作短关卡。穿过雨夜回廊，挑战两名守卫，在余火小堂选择赐福，面对二阶段无冠守望者，亲手敲响最后的古钟。

## v13 · 品质与演出升级

- **场景美术**：重做缺角、错缝铺装与弧顶墓碑，增加墙面雨蚀、玫瑰窗、刺绣破损旗幔、月光薄雾、碎石和柔边积水。保留探索路线与碰撞。静态场景由 26 次提交增至 28 次，没有新增环境光源或外部资源下载。
- **角色表现**：三种配色的织物披风有肩部固定、纵向褶皱、磨损燕尾和转身惯性；提升戒备持剑、疲劳呼吸、攻击承重与翻滚落地缓冲。剑刃仍以真实蒙皮姿态验证接触。
- **镜头演出**：可跳过的开场跟拍、首领入场镜头和区域提示。演出冻结战斗与旅途计时；继续、重试和减少动态模式直接交回操作。路径经过真实障碍验证。Space / Enter / Esc、点击跳过或手柄 A / B / Start 均可跳过。
- **战斗反馈**：增加方向性金属火花、湿地脚步水花和轻微冲击景别变化，立体声位置跟随当前镜头；保留现有战斗规则。
- **界面与声音**：统一标题、HUD、演出与结算的信息层次，互动提示优先、预警避让；新增开场与区域音乐动机。结算印记来自真实统计。演出隐藏的 HUD 不拦截键盘焦点。
- **渲染预算**：改善斜向抗锯齿和近处阴影；天空利用建筑深度减少无效着色。持续慢帧会调整分辨率、阴影和接触光效，恢复时逐步提升。帧率取决于设备与浏览器。

## 已有旅途与玩法

- **动作**：重做前、后、侧向与斜向翻滚，收身—转体—落脚与真实移动方向和时长一致。通过蒙皮接地探针避免明显穿地；修复武器挂点重复旋转和收招反转。按模型原始步幅同步走跑，增加倒退、侧移、转向与急停惯性。
- **战斗**：翻滚后的短窗口可接突刺；精准格挡强化下一剑。守卫轮流进攻、支援侧移，超出范围后归位。Boss 按距离、喝药和持续格挡选择可读的招式，半血阶段转换等待当前攻击完成。暂停保留反击窗口。
- **探索与成长**：三处有实体物件的可读残响，首次发现补充一瓶药；小堂提供生命、耐力、剑伤三选一赐福，可重新选择且不叠加。地图手记记录玩家位置、发现与战斗统计。
- **终章**：击败 Boss 后仍可探索；走到实体钟绳前按 F 敲钟结束。钟摆、声波、雨势和灯光共同变化。
- **操作**：键鼠默认移动鼠标即转镜头，无需按住拖动；支持 Pointer Lock，Esc 释放并暂停。不支持锁定的浏览器可直接悬停控制镜头。标准手柄支持战斗、双摇杆、冲刺、菜单与可用时的震动。
- **呈现与设置**：保留本地 PBR 材质与雨夜风格，增加云层、独立音乐/音效/主音量、灵敏度、减少动态和引导开关。弹窗保留暂停状态；可返回标题、继续与重试。进度与设置只保存在当前浏览器。

## 本地开发与检查

需要 Node 20+，无运行时安装依赖：

```sh
npm start
npm test
```

访问 http://127.0.0.1:8080 。GitHub Pages 从 `main` 根目录发布，所有运行资源使用相对路径，无 CDN 依赖。

112 项自动检查覆盖真实 GLB 剑刃碰撞、翻滚接地与披风固定，战术、输入、UI、声音、存档、实际关卡障碍和演出路径，以及仅通过公开控制完成两守卫、检查点、开门、两阶段 Boss 和敲钟的流程。演出整合检查包含计时冻结、自然结束、跳过、鼠标主动解锁与恢复操作。控制器流程使用可控剑刃夹具；资产测试使用生产 GLB。手柄以可注入 Gamepad API 验证，未使用实体手柄验收。

## 资源与结构

Knight 为 Patch/anymove 的 CC0 真实蒙皮资产：59,281 三角形、22 骨骼、UV 与 PBR 贴图。它是有明确许可的基础资产；不是自行雕刻的人体模型。原始待机/走跑/受击使用来源动画，持剑攻击和翻滚为代码驱动骨骼动作。完整出处见 `assets/ASSET_CREDITS.md`。

`game.js` 负责关卡控制与整合，`feel.js` 管理时序与碰撞，`tactics.js` 负责敌人决策，`journey.js` 管理旅途状态；`characters.js`/`motion.js` 负责角色，`level.js`/`surfaces.js`/`weather.js` 负责场景；`director.js` 负责演出路径，`impact.js` 负责方向性火花；`render.js`、`audio.js`、`controls.js`、`ui.js` 分别负责呈现、声音、手柄与界面。

这是持续改进的浏览器动作短关卡。场景建筑仍为程序化制作；自动检查通过不等于已经达到商业游戏的美术、动作捕捉或性能标准。
